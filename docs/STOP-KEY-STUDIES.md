# Editing-signal studies

These four preview-only proposals ask whether Backspace and Delete can share a
red warning family while remaining visibly distinct. They are prepared for a
second phase after the selected Three-Role Split physical trial; none has been
applied to hardware or physically evaluated.

The inspected US81 layout identifies Backspace as `BACKSPACE` (the wide 2-unit key)
and Delete as `DELETE` (the 1-unit key labeled Del). Both remove content in
familiar editing contexts; a color cannot confirm an application's exact action
or make one operation universally safer than the other. Esc retains the existing
signal red `#FF0000` in every proposal.

## Two tints, two placements

Each study changes exactly one key from Amber Hinge + Rose. The other editing key
stays signal red. Every other one of the 80 physical keys retains its exact keeper
color, including matched modifier pairs and all punctuation. These are not
combined with Operator Ice or Three-Role Split.

| Study | Backspace | Delete | Question |
| --- | --- | --- | --- |
| Coral Backspace | `#FF6060` | `#FF0000` | Does a wider coral tint separate the large Backspace key usefully? |
| Coral Delete | `#FF0000` | `#FF6060` | Is the same tint more useful on the smaller Delete key? |
| Ruby Backspace | `#FF0060` | `#FF0000` | Does a cooler red branch work better on Backspace? |
| Ruby Delete | `#FF0000` | `#FF0060` | Does that cooler branch distinguish Delete without suggesting a modifier role? |

Start with the coral pair. Earlier narrow amber differences were difficult to
see physically, so the coral tint widens an earlier pale-red proposal from
`#FF4040` to `#FF6060`. That is a design hypothesis, not a measured contrast
threshold. Reversing its position tests the placement rather than assuming which
editing key deserves emphasis. Keeping one key signal red also preserves a
common relationship with Esc.

The coral branch avoids the orange direction already used by Insert `#FF6A00`
and the F1–F4 bank `#FF6000`. It could nevertheless read pink or washed toward
white instead of visibly red. The ruby branch is intentionally a lower-priority
comparison: `#FF0060` is close to rose Shift `#FF0080`, so those roles may blend.
It may also be too subtle against pure red on the actual LEDs. Neither hue
relationship has been established by a physical trial.

## What would answer the question?

From typing distance, assess whether the two keys are distinguishable, still
feel related, and retain readable legends. Prefer the original if the tint is
indistinguishable, confusing or less pleasant. Do not interpret an RGB preview or
a preference as proof of faster editing, reduced errors or universal color
psychology. Key size and room light can change apparent emphasis; requested RGB
and 100% brightness do not establish equal physical luminance.

All 81 keys stay illuminated. These public JSON files are palette designs, not
Sony native imports. Previewing, sharing and downloading do not write hardware.
Any later chosen trial needs its intended slot's fresh own export and backup,
official Sony import/Save, strict fresh-export comparison and separate physical
feedback. Keep the accepted keeper available for comparison.
