# Alternate palette studies

These studies explore a different overall mood while preserving recognizable
functional groups. The accepted Amber Hinge + Rose keeper remains unchanged.
None of these designs is physically accepted; this is an offline design study,
with no hardware writes.

## Solar Draft

Solar Draft tests a warm central writing field against a cool crown and a white
number rail. The green Win/Fn pair becomes an isolated landmark. The purpose is
an enjoyable alternate visual mood, not a claim that amber improves performance,
comfort or sleep. A preference for green in earlier comparisons does not decide
this separate question in advance.

| Functional group | Keys | Requested RGB |
| --- | --- | --- |
| Letters, Space and ordinary punctuation | 35 | Amber `#FFB000` |
| Digits and both bracket keys | 12 | White `#FFFFFF` |
| Win/Fn hinge | 2 | Green `#00FF00` |
| F1–F4 | 4 | Violet `#4400FF` |
| F5–F8 | 4 | Azure `#00A0FF` |
| F9–F12 | 4 | Cyan `#00FFFF` |

Ordinary punctuation means minus/underscore, equals/plus, backslash/pipe,
semicolon/colon, quote, comma, period and slash/question mark. Each physical key
has one light for both shifted and unshifted legends. Together these groups
change exactly 61 keys relative to the keeper.

The remaining 20 keys retain their keeper colors: Tab/Caps/Enter violet
`#B000FF`, Ctrl blue-violet `#4400FF`, Alt magenta `#FF00E0`, Shift rose
`#FF0080`, tilde/arrows azure `#00A0FF`, Esc/Backspace/Delete red `#FF0000`,
Insert orange `#FF6A00` and Page Up/Page Down yellow `#FFE000`. Left/right modifier
pairs remain matched. All 81 keys remain illuminated at the requested 100%
brightness; that does not establish equal apparent brightness across hues.

## What would make it useful?

Ask whether the entire composition feels like an enjoyable alternate while key
legends and functional groups remain easy to recognize from typing distance.
Keep it as an alternate only after an actual person finds that combination useful.
It is a whole-composition study: a preference cannot establish the causal effect
of one changed key or one color.

Possible reasons to reject or revise it are white digits overpowering the writing
field, red/orange stop and Insert keys merging with the amber field, violet crown
keys merging with the command frame, or any legends becoming difficult to read.
These are unresolved design risks, not observed faults. Screen RGB previews do
not measure LED output, comfort, attention or typing performance.

Preview and share it without changing hardware. The downloadable JSON is a
palette design, not a Sony native import. Any chosen physical trial still needs
the intended slot's fresh own export and backup, official Sony import/Save,
strict fresh-export verification and separate physical feedback. Never replace
the accepted keeper merely to test this alternative.
